# The name: type[writer]

Checked 29 October 2026.

## Where the name appears

| Place | Shown as |
|---|---|
| Web page title, home-screen name, web manifest | type[writer] |
| Wordmark in the app | type[writer], brackets in a lighter weight |
| GitHub repository and web link | `typewriter` (GitHub names allow only letters, digits, `-`, `_` and `.`) |
| npm package, saved settings key | `typewriter` (internal, unchanged so saved pages survive) |
| Mac and iPhone bundle id (later) | something like `com.palmcreekmusic.typewriter` |

## App Store

- **Name rules.** App names can be up to 30 characters and must be unique on the store. Search results cut titles at about 26 characters. Punctuation is allowed but Apple doesn't index it, so brackets cost characters without helping search.
- **How search will read it.** Expect "type[writer]" to be indexed as the words *type* and *writer*, not *typewriter*. People searching "typewriter" need to find us through the subtitle and keyword field.
- **Recommended listing:**
  - Name: `type[writer]: Typed Captions` (28 characters)
  - Subtitle (30): `Typewriter text for photos` (26)
  - Keywords (100): typewriter, typed, caption, vintage, retro, film, letter, whiteout, ribbon, typing video, overlay
- **Nearby apps.** "[Typewriter: Typing Video Maker](https://apps.apple.com/us/app/typewriter-typing-video-maker/id1455777996)" (typing-animation videos with key sounds, subscriptions plus $27.99 lifetime) is the closest competitor and already owns the plain word in its title. Others: [RetroType](https://apps.apple.com/us/app/retrotype/id6752917326), [miTypewriter](https://apps.apple.com/us/app/id340871428), [Typewrite](https://apps.apple.com/py/app/typewrite-virtual-typewriter/id6450997843?l=en-GB). The bracket styling sets us apart from all of them.
- **Can't be confirmed from here.** Whether the exact name is free only shows when you create the app record in App Store Connect, which reserves the name. Do that early, once the Apple Developer account exists. If it's taken, fall back to `type[writer] Captions`.

Sources: [AppTweak, App name guidelines](https://www.apptweak.com/en/aso-blog/app-name-guidelines-and-best-practices), [Apple Developer Forums on the 30-character limit](https://developer.apple.com/forums/thread/91722).
